# 展示会スタッフ専用 注文管理

NEO TOKYO 2026 を想定したスマホ優先の注文管理ツールです。商品検索から注文登録、本社共有、後日受取、会計・受け渡し、印刷・PDF提出までを扱います。

## 完成版の主な機能

- 3,861商品の最新版マスターを品番・商品名で検索
- 商品追加専用のフル画面（検索バーを上部、固定入力キーを検索バー直下、進むボタンを下部に固定）
- 検索結果から商品を追加しても候補を閉じず、同じ品番群を続けて複数追加（入力クリア時だけ候補を閉じる）
- 画面を動かさず品番を入力できる固定入力キー（スマホ型3列テンキー／英字QWERTY切替）
- 固定入力キーは「◀ 左」「右 ▶」ボタンで片手操作しやすい位置へ切替（選択位置を端末に保存）
- 国内通常注文、即時現売り、後日会場受取、ホテル配送、指定先配送
- 現売りの「商品の渡し方」は4種類を1列で表示
- 「要対応」「受取待ち」「完了」の3フォルダで迷わず管理
- 後日受取・配送は「本社共有済み」を明示
- 国内通常注文を帰社後にまとめて印刷
- 展示会終了後に全注文を一覧・明細付きでPDF保存・印刷
- 注文カードの「印刷対象」表示は省略し、印刷メニューから保存済み注文をまとめて出力
- 通信失敗時は端末へ保存し、「未同期」を明示
- 登録スタッフ全員で同じ注文画面を共有（3秒ごと・画面復帰時・通信復帰時に自動同期）
- 「完了」に入った注文を含め、注文詳細から商品・お客様情報・受け渡し内容を修正
- 本社共有が必要な注文は、共有状態ボタンの直前から注文書を印刷・PDF保存
- お客様へQRコードを提示し、スマートフォンに表示された注文控え画像を長押しで保存
- お客様控えのお客様名には「様」を自動付与（入力済みの敬称は重複させない）
- 注文作成画面を途中で閉じても、検索文字・追加商品・入力内容を保持して再開
- お客様控えには展示会名・本社共有・社内対応状態を載せず、注文内容だけを表示
- 韓国展示会ツールを基準にした、ロゴ・注文情報・商品明細・合計が1枚で読める控え／印刷レイアウト

- 71件へ「新卸」を反映

## 起動

ES Modules とCSV読込を使うため、ファイルを直接開かずHTTPサーバーから起動します。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4173/` を開きます。本番設定は `online-config.js` の `onlineEnabled: true` です。既存の注文登録APIは本番GitHub PagesのOriginだけを許可しているため、ローカルではログイン画面の「端末モードで開始」を使います。

## 展示会での運用フロー

### 国内通常注文

店舗、電話番号、卸屋・帳合先、受注担当者を入力して登録すると、その場で受注完了です。「完了」に保存され、帰社後に「印刷・PDF」から国内通常注文だけをまとめて印刷できます。

### 現売り対応

1. 在庫あり・その場渡し：会計と商品のお渡し完了で登録し、そのまま「完了」
2. 翌日・翌々日受取：本社未共有なら「要対応」、共有済みなら「受取待ち」、会計・お渡し後に「完了」
3. ホテル／指定住所へ配送：本社未共有なら「要対応」、共有済みになった時点で本社へ引き継ぎ、「完了」

このツールはSlackへ自動送信しません。本社共有欄の「印刷・PDFで本社へ共有」で注文書を用意し、各自Slackなどで実際に共有した直後に「本社共有済み」を押します。

## 印刷・PDF

- 「国内通常注文をまとめて印刷」：帰社後の伝票打ち提出用
- 「展示会の全注文データをPDF・印刷」：展示会終了後の提出用。注文一覧と全明細を出力
- 注文詳細の「この注文をPDF保存・印刷」：個別確認用
- 注文詳細の「お客様控えQR・画像」：お客様のスマートフォンへQRを表示し、韓国展示会ツールと同じように画面上の控え画像を長押しで保存

ブラウザの印刷画面で「PDFに保存」を選ぶだけでPDFにできます。メールやSlackとの連携はありません。

注文の内容に誤りがあった場合は、「要対応」「受取待ち」「完了」のどのフォルダでも注文詳細を開き、「この注文を修正」から訂正できます。登録スタッフでログイン中の修正は全スタッフへ同期されます。

## Supabase同期

プロジェクト参照IDは `qdexhwgzawisiklekfzm` です。公開版では登録済み・有効なスタッフでログインすると、同じ展示会の注文と状態更新を全スタッフで共有します。3秒ごとの同期に加え、画面へ戻った時と通信が復帰した時にも直ちに再同期します。上部には最終同期時刻を表示します。

「端末モード（共有されません）」は通信障害時の一時保存用です。他のスタッフからは見えないため、通常は必ず登録スタッフのアカウントでログインしてください。service role key、個人のアクセストークンなどの秘密情報をブラウザ側ファイルやGitへ保存してはいけません。
