# 展示会スタッフ専用 注文管理

NEO TOKYO 2026 を想定したスマホ優先の注文管理ツールです。商品検索から注文登録、本社共有、後日受取、会計・受け渡し、印刷・PDF提出までを扱います。

## 完成版の主な機能

- 3,861商品の最新版マスターを品番・商品名で検索
- 商品追加専用のフル画面（検索バーを上部、固定テンキーと進むボタンを下部に固定）
- 画面を動かさず品番を入力できる固定テンキー（数字・ハイフン／英字切替）
- 国内通常注文、即時現売り、後日会場受取、ホテル配送、指定先配送
- 「要対応」「受取待ち」「完了」の3フォルダで迷わず管理
- 後日受取・配送は「本社共有済み」を明示
- 国内通常注文を帰社後にまとめて印刷
- 展示会終了後に全注文を一覧・明細付きでPDF保存・印刷
- 通信失敗時は端末へ保存し、「未同期」を明示

## 商品マスター

2026年8月1日改定分を次のルールで統合しています。

- 基準: `無題のスプレッドシート (1).xlsx`（3,861商品）
- 改定: `改正価格表2026.8.1～（卸価格表）小売価格税抜・税込　株式会社サンニシムラ1.xlsx`（71商品）
- 商品コード完全一致で71件すべて照合し、基準の卸価格と改定表の「現卸」も全件一致
- 71件へ「新卸」を反映
- 改定表の商品はすべて基準マスター内に存在したため、今回の新規追加は0件
- コード `63463` は基準データに異なる2商品があるため、自動改番せず両方を選択可能
- `141-801` と `141-802` は卸価格が「未定」のため、検索はできるが注文への追加は不可

## 起動

ES Modules とCSV読込を使うため、ファイルを直接開かずHTTPサーバーから起動します。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4173/` を開きます。本番設定は `online-config.js` の `onlineEnabled: true` です。既存の注文登録APIは本番GitHub PagesのOriginだけを許可しているため、ローカルではログイン画面の「端末モードで開始」を使います。

## 展示会での運用フロー

### 国内通常注文

店舗、電話番号、卸屋・帳合先、受注担当者を入力して登録すると、その場で受注完了です。「完了」に保存され、帰社後に「印刷・PDF」から国内通常注文だけをまとめて印刷できます。

### 現売り対応

1. 在庫あり・その場渡し：会計と商品のお渡し完了で登録し、そのまま「完了」
2. 翌日・翌々日受取：本社未共有なら「要対応」、共有済みなら「受取待ち」、会計・お渡し後に「完了」
3. ホテル／指定住所へ配送：本社未共有なら「要対応」、共有済みになった時点で本社へ引き継ぎ、「完了」

このツールはSlackへ自動送信しません。各自Slackなどで実際に本社へ共有した後、注文カードの「本社共有済みにする」を押します。

## 印刷・PDF

- 「国内通常注文をまとめて印刷」：帰社後の伝票打ち提出用
- 「展示会の全注文データをPDF・印刷」：展示会終了後の提出用。注文一覧と全明細を出力
- 注文詳細の「この注文をPDF保存・印刷」：個別確認用

ブラウザの印刷画面で「PDFに保存」を選ぶだけでPDFにできます。メールやSlackとの連携はありません。
